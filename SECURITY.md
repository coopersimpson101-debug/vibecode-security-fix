# Security policy

This repo contains instructions for an AI coding agent, not running software. A "vulnerability" here means something in `SKILL.md` that could lead an agent to:

- damage a user's app or data, for example by writing to production or skipping approval steps,
- leak secrets, for example by printing them to chat or logs, or
- probe systems the user doesn't own.

**To report one,** use [GitHub private vulnerability reporting](../../security/advisories/new) instead of a public issue. Expect a reply within 7 days.

Bugs in *your own app* that this skill found are yours to fix. Please don't report those here.
